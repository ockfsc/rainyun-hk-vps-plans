## 退款：原路退回不是自动发生的

这是搜“支付宝付款VPS”的人最该看、前排文章又最少写的一段。

支付宝付的款，钱要回到支付宝，得同时满足三个前提：商家接入了支付宝的退款接口、这笔交易还在可退期限内、商户账户状态正常。三个里缺一个，原路退回就走不通，只能转人工。

钱具体退到哪，取决于你当时怎么付的：

| 付款方式 | 退款去向 | 到账特征 |
| --- | --- | --- |
| 支付宝余额 | 支付宝余额 | 通常最快 |
| 花呗 | 恢复花呗额度 | 已分期的要看账单怎么调整 |
| 信用卡 | 原信用卡 | 银行处理，可能跨账单日 |
| 储蓄卡 | 原储蓄卡 | 银行处理，可能延迟 |
| 余额宝 | 余额宝或余额 | 看通道规则 |
| 企业支付宝 | 可能退到对公账户 | 要走财务流程 |

**雨云自己的退款条款，我在公开资料里没有核验到明确的期限和条件文本。** 这一条不能猜，付款前用工单问清三句话就够：

1. 支付宝付的订单，退款是否原路退回支付宝？
2. 是按未使用天数折算，还是只支持未开机退款？
3. 特价机、年付机参不参与退款？

真要走退款流程，工单别只写“申请退款”，把六项写全，能省掉好几个来回：订单号、支付宝交易号、购买时间、退款原因、请求原路退回的金额、原路退回失败时的人工打款路径。按天折算的，把未使用天数一起算进去。

支付宝交易号在 App 里找：我的 → 账单 → 找到那一笔 → 详情 → 订单号或商家订单号。用花呗付的，账单里显示成“花呗-某某商户”。电脑端登录支付宝进“交易记录”，按时间筛也行。

商家发起退款后，在支付宝 App 的账单里搜商家名称就能看到退款记录。如果状态显示“退款失败”，常见原因是商户余额不足、交易超过可退期限、支付方式不支持原路退回、订单已结算这四种。这时候让商家改走人工打款，对公转账或者支付宝转账都行，到账后要求在工单里回一句“已退款”，留个书面记录。

原路退回有通道期限。超期之后商户那边可能已经调不动退款接口了，同样的办法，人工打款加书面确认。

协商不成还有后手：支付宝账单里找到该笔交易，走“投诉 → 退款纠纷”；金额大的，查清经营主体名称后可以向 12315 投诉。前提是你知道对方对公主体叫什么，所以下单前顺手看一眼官网底部的备案信息，不费事。
